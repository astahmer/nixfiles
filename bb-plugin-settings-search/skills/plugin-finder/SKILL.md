# Plugin Finder

Use the **Add plugins** sidebar page to search BB's plugin catalog and install a
plugin.

## Install a plugin

1. Search by plugin name or the capability you need.
2. Check the plugin description, publisher, marketplace, and compatibility.
3. Select **Add** to review the exact resolved source.
4. Confirm **Add plugin** only after checking the publisher and source.

Third-party marketplace entries are not reviewed by BB. Incompatible entries
cannot be added from this page.
