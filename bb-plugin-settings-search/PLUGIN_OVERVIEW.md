# Settings Search

## User problem

BB Settings has many categories and controls, while only one category is mounted at a time. Finding a setting means scanning the sidebar or already-open page.

## Behavior

- Adds one small search field above the Settings navigation.
- Searches an index of settings across categories, including labels, help text, and options.
- Displays clickable results with setting and category context.
- Opens the result's category and scrolls to the setting when selected.
- Highlights matching categories and settings visible on the current page.
- Keeps the active category visible and uses Escape to clear the query.
- Removes its field and decorations when leaving Settings or reloading the plugin.
